# Functional Requirements Document (PRD)

- User can search for restaurants based on location, cuisine, and ratings. The search results should display relevant information such as restaurant based on location .
- User can add items to cart
- User can checkout by making payment through various payment methods (credit card, debit card, digital wallets).
- User should be notified one order if placed successfully.

# Non Functional Requirements

- Each part of design should be scalable and maintainable.
